# Clinical NLP: Diagnosis & Procedure Burden Analysis (2022–2025)

## 📌 Project Overview

This project applies advanced Clinical Natural Language Processing (NLP)
techniques to hospital theatre operation data (2022–2025) to uncover
surgical burden patterns, case complexity, and diagnosis–procedure
relationships.

Unlike basic text analysis, this work follows a real-world healthcare NLP
workflow designed for messy, unstructured clinical text.

---

## 🎯 Objectives

- Identify dominant surgical burden themes across specialties
- Discover hidden clinical patterns using unsupervised NLP
- Quantify diagnosis → procedure linkages
- Assess emergency vs elective drivers of theatre workload
- Integrate demographic and anaesthesia context for planning insights

---

## 🧠 Methods & Techniques

### Clinical Text Processing
- Cleaning and normalization of diagnosis and procedure text
- Handling abbreviations, spelling variants, and clinical shorthand
- Separation of diagnosis and operation narratives

### NLP & Machine Learning
- TF-IDF feature engineering with clinical n-grams
- KMeans clustering for surgical theme discovery
- Latent Dirichlet Allocation (LDA) for topic modeling
- Diagnosis–procedure pair mining for theatre intelligence

### Contextual Enrichment
- Emergency vs elective stratification
- Age and sex analysis
- Specialty ownership
- Anaesthesia utilization patterns

---

## 📊 Key Findings

- Obstetric emergencies (Caesarean sections) are the largest theatre drivers
- Some pathways are highly standardized (e.g. adenotonsillectomy)
- Other diagnoses show multi-procedure complexity (e.g. obstruction, neuro cases)
- Anaesthesia burden aligns strongly with clinical themes
- Significant terminology variation exists in clinical documentation
